# WebsiteManager V3

A fast, simple launchpad that opens your favorite websites and apps with one click — now with full voice activation.

## Overview

WebsiteManager is a lightweight Windows launcher that lets you open your most-used websites and apps instantly.  
Version 3 adds full voice activation and 24 new apps, so you can launch anything with a click or by simply saying its name.

## Key Updates in V3

- Voice Activation — Open any website or app using your voice
- +24 New Apps — Expanded library with 24 additional apps and services
- Faster and more reliable launching
- Cleaner, more responsive interface

## Features

- One-click website & app launcher
- Full voice control
- Large library of popular apps and websites
- Lightweight and fast
- Simple, clean interface

## Download & Installation

1. Download the `WebsiteManagerV3.exe` file
2. Run the `.exe` file
3. (Optional) Create a desktop shortcut for quick access

No installation required — just download and run.

## How to Use

### Click Mode
- Open WebsiteManager V3
- Click any button to instantly open the website or app

### Voice Mode
1. Enable voice activation inside the app
2. Say the name of the website or app (e.g. “YouTube”, “Gmail”, “Spotify”)
3. The app opens automatically

Make sure your microphone is enabled and allowed for the application.

## System Requirements

- Windows 10 or Windows 11
- Microphone (required for voice activation)
- Internet connection
